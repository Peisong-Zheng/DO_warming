# DO-like Asian monsoon transition timing

This repository contains the analysis code for a manuscript on whether
DO-like Asian monsoon transition timings in the Rousseau et al. (2023)
catalogue are organized by slow climate background state and orbital phase.

The main event catalogue is the 0--640 kyr BP weak- and strong-monsoon start
series extracted from the Cheng et al. (2016) Chinese speleothem composite by
Rousseau et al. (2023). The core analyses combine:

- circular Rayleigh tests for orbital phase clustering;
- binned Poisson predictive-information models with event-process controls;
- lagged predictive-information scans for LR04, CO2, and precession phase;
- sensitivity checks for bin width, age uncertainty, KS detection window,
  additional forcings, bootstrap LR nulls, and an independent Barker et al.
  (2011) D-O warming catalogue.

## Project Layout

```text
data/
  raw/          Input datasets used by the scripts.
  processed/    CSV outputs generated by each analysis script.

figures/        Script-level figure outputs, grouped by script name.

monsoon_paper/
  main.tex      Main manuscript.
  SI.tex        Supporting Information.
  reference.bib Reference library.
  figures/      Overleaf-ready PDF copies named Fig01.pdf, FigS01.pdf, ...

toolbox/        Shared model/statistical utilities used by the scripts.

run_logs/       Timestamped logs from runner and validation scripts.
```

`data/raw/` is treated as input-only. Script outputs go to
`data/processed/<script_name>/` and `figures/<script_name>/`.

## Quick Start

To regenerate the main-text analyses without running sensitivity experiments:

```bash
python run_main_paper_workflow.py
```

This runs:

1. `Predictive_information_model.py`
2. `Orbital_phase_rayleigh.py`
3. `Lagged_predictive_information.py`
4. `paper_figure_export.py`

Use a dry run to inspect the commands:

```bash
python run_main_paper_workflow.py --dry-run
```

The runner writes timestamped logs to `run_logs/main_paper_workflow/`.

## Terminology

- **Event-process baseline**: same-type event history plus local sampling
  resolution. This controls recent event occurrence and uneven speleothem
  sampling before testing climate/orbital predictors.
- **Climate-state model**: event-process baseline plus LR04 and CO2.
- **Full predictive model**: climate-state model plus precession phase
  represented by sine and cosine terms.
- **Extended baseline**: the full predictive model used as the reference in
  the additional-forcing sensitivity experiment.

## Main Analysis Scripts

| Script | Purpose | Main outputs |
|---|---|---|
| `Predictive_information_model.py` | Fits the event-process baseline, climate-state model, and full predictive model for Rousseau strong/weak monsoon starts. Also creates the main input/fitted-rate figure and model-comparison figure. | `data/processed/Predictive_information_model/`; `figures/Predictive_information_model/`; manuscript `Fig01`, `Fig03` |
| `Orbital_phase_rayleigh.py` | Converts precession and obliquity into phase variables and tests whether event timings cluster at preferred phases. | `data/processed/Orbital_phase_rayleigh/`; `figures/Orbital_phase_rayleigh/`; manuscript `Fig02`, `FigS01`, `FigS02` |
| `Lagged_predictive_information.py` | Scans lagged predictive-information gains for LR04, CO2, and precession phase. In the core lag figure, LR04 and CO2 are added to the event-process baseline, while lagged precession phase is added to the climate-state model. | `data/processed/Lagged_predictive_information/`; `figures/Lagged_predictive_information/`; manuscript `Fig04` |
| `Bin_hazard_phase_poisson.py` | Earlier binned hazard model without event-process controls. It is kept because one SI companion figure contrasts LR04+CO2-only and LR04+CO2+precession fits without the noisier event-process baseline. | `data/processed/Bin_hazard_phase_poisson/`; `figures/Bin_hazard_phase_poisson/`; manuscript `FigS03` |
| `paper_figure_export.py` | Copies only paper-referenced PDFs from `figures/` into `monsoon_paper/figures/` with manuscript names. Plotting scripts also call its helper functions when saving paper figures. | `monsoon_paper/figures/Fig*.pdf` |

## Sensitivity and Diagnostic Scripts

| Script | Purpose | Notes |
|---|---|---|
| `Bin_hazard_phase_poisson_sensitivity.py` | Tests whether Antarctic temperature, obliquity, eccentricity, and 65N summer-solstice insolation add information beyond the full predictive model. | Produces SI extra-forcing figures. |
| `Bin_hazard_phase_poisson_binwidth_sensitivity.py` | Repeats the core predictive-model comparisons for bin widths from 0.2 to 1.0 kyr. | Checks that conclusions are not a narrow consequence of the 0.2 kyr bin width. |
| `Composite_age_uncertainty_core_sensitivity.py` | Perturbs event ages under a conservative Cheng composite age-uncertainty envelope and repeats Rayleigh and predictive-information checks. | Produces SI age-uncertainty summary. |
| `KS_window_core_experiment_sensitivity.py` | Compares the 0.4--4 kyr and 0.6--4 kyr Rousseau KS transition catalogues. | Checks dependence on the KS detection window. |
| `Predictive_information_bootstrap_diagnostics.py` | Uses reduced-model parametric bootstrap nulls for the two central LR tests. | Slower than the other diagnostics; default is 2000 bootstrap replicates. |
| `Barker2011_do_predictive_information.py` | Repeats Rayleigh and predictive-information analyses for the Barker et al. (2011) variable-threshold D-O warming catalogue. | Independent catalogue check, treated as a sensitivity result. |

## Shared Code

`toolbox/` contains small shared utilities used to avoid repeated
implementations:

- `toolbox/model_stats.py`: AIC/AICc/BIC, likelihood-ratio p values,
  log-likelihood gains, and bits/event summaries.
- `toolbox/poisson.py`: binned Poisson design matrices, log likelihoods,
  optimization objective, and fitted-rate conversion.

The project still keeps plotting code inside each analysis script because many
figures are hand-tuned and intentionally differ in small ways.

## Typical Workflows

Refresh the main-text results:

```bash
python run_main_paper_workflow.py
```

Refresh a specific sensitivity experiment:

```bash
python Bin_hazard_phase_poisson_sensitivity.py
python Composite_age_uncertainty_core_sensitivity.py
```

Refresh the Overleaf-ready figure folder from existing project-level figures:

```bash
python paper_figure_export.py
```

Compile the manuscript from `monsoon_paper/` using your preferred LaTeX
workflow. The manuscript expects figures in `monsoon_paper/figures/`.
